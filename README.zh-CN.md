# WA 实时翻译 · WhatsApp Web 中文翻译插件

**[English](README.md)** | 中文

在 WhatsApp Web 里跟客户聊天时，**每条客户消息下方自动多出一行中文译文**，不用切到翻译软件，也不用复制粘贴。

![效果截图](docs/screenshot-chat.png)

- 自动识别语种：英语、西班牙语、葡萄牙语、阿拉伯语、法语、德语、俄语、土耳其语、印尼语……（Google 通道支持 100+ 语种）
- 译文直接嵌在消息气泡内，原文保留不动
- 可带上文翻译：把客户前几条消息一起送给引擎，大幅减少「省标点导致翻错」的情况
- 单条翻得不准？点译文前的「AI」小标签，立刻用大模型重译这一条
- 已经翻译过的句子走本地缓存，重复内容秒出、不重复请求
- 手动输入的中文自动跳过；纯表情、纯数字、纯链接也跳过
- 默认只翻译**客户发来的**消息（可在设置里改成双向）

---

## 一、安装（1 分钟）

1. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车
2. 右上角打开「**开发者模式**」
3. 点左上角「**加载已解压的扩展程序**」，选择本文件夹 `wa-translator`
4. 打开（或刷新）`https://web.whatsapp.com`，进入任意聊天窗口即可看到译文

> 装好后建议把插件图标固定到工具栏，方便随时开关。

## 二、使用

| 操作 | 位置 |
| --- | --- |
| 开 / 关翻译 | 点工具栏图标 → 右上角开关 |
| 切换译文语言（简体 / 繁体） | 弹窗「译成」 |
| 切换翻译引擎 | 弹窗「翻译引擎」或设置页 |
| 也翻译自己发出的消息 | 弹窗里的勾选项 |
| **某条翻得不准，单独重译** | **点译文前的「译 · 葡语 AI」小标签，或双击译文块** |
| 查看引擎配置、测试连接 | 弹窗 →「设置」 |

翻错了或者网络抖了一下，译文位置会出现「⚠ 翻译失败 · 点此重试」，直接点一下就行。

## 三、翻得准不准：三档精度

客户写消息不打标点，机翻最容易错在**断句和状语归属**。真实例子：

| | |
| --- | --- |
| 原文 | `Olá desculpe a demora na segunda feira vejo isso` |
| ✗ 单句机翻 | 抱歉周一耽搁了，我看到了这个 |
| ✓ 正确 | 你好，抱歉久等了，这事我周一再看看 |

差别在于 `na segunda feira` 修饰的是 `vejo isso`（周一我再看），不是 `desculpe a demora`。
**单句直译看不到这个关系，只有带上下文的模型能判断。** 所以有了下面三档：

| 引擎 | 是否要配置 | 精度 | 说明 |
| --- | --- | --- | --- |
| **Google**（默认） | 不用 | ★★☆ | 免费、快、语种最全；只看单句，省标点的长句容易错 |
| **DeepL** | 要 API Key | ★★★ | 欧美语种更地道，支持把上文作为语境（`context` 参数）；免费额度 50 万字符/月 |
| **大模型** | 要 API Key | ★★★★★ | 能读懂上下文、行业术语、客户语气，最接近人工客服译文 |

### 怎么让译文最准（推荐配置）

1. 弹窗 →「设置」→ 引擎选 **大模型**
2. 填 Base URL / API Key / 模型名（下面有现成的）
3. 保持 **「带上文一起翻译」打开**，携带条数选 **2 条**
4. 把常用的外贸词填进 **术语表**（每行 `原文=译文`），命中就强制按你的译法走
5. 点「测试连接」，会直接用那句葡语跑一遍，能看到当前引擎和大模型的译文对比

大模型通道兼容 OpenAI 接口，填三项即可：
- DeepSeek：`https://api.deepseek.com/v1`，模型 `deepseek-chat`（1 元约可译 30 万字，日常够用很久）
- 通义千问：`https://dashscope.aliyuncs.com/compatible-mode/v1`，模型 `qwen-plus`
- OpenAI：`https://api.openai.com/v1`，模型 `gpt-4o-mini`

如果自定义域名第一次访问失败，是浏览器权限没给：再点一次「测试连接」，弹窗里点「允许」。

### 三个精度的具体机制

**1. 上下文（Context）**
每条消息翻译时，会把同一会话里紧邻的前 1–2 条消息一起送给引擎，并明确标注「仅作背景，不要翻译」。客户省掉标点的句子、代词指代、承接上句的回答，靠这个就能判对。
上下文只在内存里传递，不入缓存、不出本机以外。

**2. 专用提示词**
大模型通道内置的提示词针对即时通讯场景写死了几条硬规则：先断句再译、核对时间状语和否定词的归属、保留表情/金额/型号/链接、只输出译文。
你可以在设置页覆盖它，支持 `{lang}` 占位符。

**3. 术语表**
外贸高频词（`pedido=订单`、`prazo de entrega=交期`、`MOQ=最小起订量`）填进去后，命中才注入提示词，不命中不占 token。同一批客户反复问同样的问题，译法就能保持一致。

### 单条重译

即使整体用的是 Google，遇到翻得别扭的一句，**点译文前的「译 · 葡语 AI」标签**（或双击译文块）会立刻用大模型带上下文重译这一条，并写回缓存。
只重译这一条，不影响其它消息，也不用改全局设置。


## 四、文件说明

```
wa-translator/
├── manifest.json     # 扩展清单（MV3）
├── content.js        # 核心：找到消息 → 取正文 → 插译文块
├── content.css       # 译文块样式（含深色模式）
├── background.js     # 后台：真正发翻译请求（Google / DeepL / 大模型）
├── popup.html/js/css # 工具栏弹窗
├── options.html/js/css # 设置页
├── diagnose.html/js  # 诊断页：WhatsApp 改版导致失效时用它定位
├── preview.html      # 样式预览（本地打开即可看效果，不参与运行）
└── icons/            # 图标
```

**WhatsApp 改版了怎么办？** 先点弹窗里的「诊断」，它会告诉你卡在哪一步（没找到消息 / 取不到正文 / 接口失败），并给出可以复制的报告。

从 1.1.0 起，正文识别是四级兜底策略，按稳定程度依次尝试：
`[data-pre-plain-text]` → `span.selectable-text` → `.copyable-text` → 最内层 `[dir]` 文本块，
所以即便 WhatsApp 把 class 全换掉（它们本来就是构建哈希），只要消息行还带 `data-id` 就能继续工作。
真要动代码，只需要改 `content.js` 里的 `extract()` 和 `collectMessageEls()`。

## 五、隐私

- 插件不收集、不上传任何数据，没有自己的服务器
- 只有在你开启翻译时，**被翻译的那条消息文本**才会发送给你所选的翻译服务商（Google / DeepL / 你自己填的大模型）
- 译文缓存存在浏览器本地（`chrome.storage.local`），可随时在设置里一键清空
- 不读取其它网页，权限仅限 `web.whatsapp.com` 与翻译接口域名

## 六、常见问题

**装完没反应？** 扩展只在页面加载时注入，刷新一下 WhatsApp 页面（F5）。

**一条消息都没翻译，弹窗显示「未识别到消息」？** 说明插件在跑、但没认出消息节点（通常是 WhatsApp 改版）。点弹窗底部的「**诊断**」，页面会显示：找到几条消息、正文有没有取到、请求成功几次、失败原因，还能一键复制报告。1.1.0 的兜底策略已经覆盖了绝大多数改版情况；如果仍然失效，把复制的报告发出来就能定位。

**某些消息没有译文？** 图片/语音/贴纸本身没有文字；引用回复里的旧消息不重复翻译；纯表情和纯链接会跳过。

**译文出现「翻译失败」？** 鼠标悬停能看到具体原因。常见是请求太频繁（429）或代理没开，点一下重试即可。

**译文不准 / 句子被理解错？** 单句机翻的通病，尤其是客户不打标点时。三步解决：
1. 设置页保持「带上文一起翻译」开启（携带 2 条）；
2. 引擎换成大模型（精度差别最大的一步，详见第三节）；
3. 单条重译：点译文前的「AI」小标签。

**换了引擎，旧消息还是旧译文？** 切换引擎会自动清空译文缓存并重译，不用手动处理。若还看到旧的，点弹窗「清空缓存」。

**长消息？** 单条默认最多翻译 3000 字（设置页可调），超出部分会自动截断并加省略号，同时后台按句子分片请求，不会返回不完整结果。

**会影响 WhatsApp 速度吗？** 只在有新消息时翻译，并发上限 2 条，其余排队；已翻译过的内容直接读缓存。

**用的是 WhatsApp Business 账号，能用吗？** 能。WhatsApp Business 账号在浏览器里同样登录 `web.whatsapp.com`，页面代码和个人版完全一致，插件照常工作，不用任何额外设置。

**用的是 WhatsApp Business 桌面客户端（Windows / Mac 安装版）？** 不行——Chrome 扩展只能跑在 Chrome 里，装好的桌面 App 加载不了扩展。两个替代方案：
1. 改用浏览器打开 `web.whatsapp.com` 登录同一个 Business 账号（扫一次码即可，聊天记录会同步）；
2. 想保留「独立窗口」的体验：在 Chrome 里打开 `web.whatsapp.com` → 右上角菜单 → 投放、保存和共享 → **创建快捷方式** → 勾选「在窗口中打开」。这样得到一个没有地址栏的独立窗口，翻译依然生效。

**用的是 WhatsApp Business API / 第三方客服后台（如 WATI、respond.io、Sleekflow）？** 这些后台是另一套界面，插件目前不匹配。需要的话可以加上，把后台地址告我即可。
